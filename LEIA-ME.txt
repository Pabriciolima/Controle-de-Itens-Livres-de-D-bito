# CONTROLE DE ITENS LIVRES DE DÉBITO — GUIA DE INSTALAÇÃO

Arquivos:
- index.html: estrutura do sistema
- style.css: visual premium e responsivo
- script.js: regras, Supabase, anexos, filtros e relatórios CSV
- config.js: URL e chave pública do Supabase
- supabase-estrutura.sql: banco, funções, segurança, Storage e auditoria

IMPORTANTE:
- Não abra com duplo clique em produção.
- Para teste local, use a extensão Live Server do VS Code.
- Nunca use secret key ou service_role no config.js.
